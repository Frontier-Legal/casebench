# httpx2 for Casebench's own HTTP calls

Amends [0018](0018-httpx-jsonpath-ng-and-pyyaml.md): httpx2 replaces httpx. jsonpath-ng and PyYAML stay.

## Context and problem statement

Casebench makes HTTP calls in two places: the http target sends cases to an agent, and the recording proxy forwards calls to model APIs and backends. Decision 0018 chose httpx and noted that its last release was in December 2024. In 2026 the Anthropic and OpenAI SDKs moved to httpx2, the pydantic team's continuation of httpx, which keeps httpx's API.

## Considered options

- httpx2
- Stay on httpx
- aiohttp

## Decision outcome

Chosen option: "httpx2", because it is maintained (2.13.1, BSD-3-Clause), keeps the same client API, so the change is the import, and it is already installed in any environment that has the Anthropic or OpenAI SDK.

### Consequences

- Good, because Casebench depends on a maintained HTTP client, the same one the agents it measures use.
- Bad, because httpx2 is younger than httpx; if its API diverges, the two call sites are small.

## Revisit when

httpx2 stops being maintained, or its API diverges from what the two call sites use.
