Casebench follows [SemVer](https://semver.org/). While the version is 0.x, a minor release may change the command line, the file formats or the Python interface, and every break is named under **Breaking changes**. Each release is written from the commits that went into it, and published to [PyPI](https://pypi.org/project/casebench/).
