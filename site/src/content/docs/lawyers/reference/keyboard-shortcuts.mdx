The review queue and the blind comparison work without the mouse. Press <kbd>?</kbd> in the workbench to see this list.

| Keys | Does |
| --- | --- |
| <kbd>1</kbd> to <kbd>9</kbd> | Picks the numbered choice on the highlighted row: Pass, Fail; Approve, Edit, Reject |
| <kbd>↓</kbd> or <kbd>J</kbd> | Next row |
| <kbd>↑</kbd> or <kbd>K</kbd> | Previous row |
| <kbd>A</kbd>, <kbd>B</kbd>, <kbd>E</kbd> | In Compare runs: answer A is better, answer B is better, or equal |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Finishes the item and opens the next. <kbd>Ctrl</kbd> <kbd>Enter</kbd> on Windows and Linux. |
| <kbd>Esc</kbd> | Leaves a text box |
| <kbd>?</kbd> | Shows the shortcuts |

On a phone or tablet, tap the buttons instead.
